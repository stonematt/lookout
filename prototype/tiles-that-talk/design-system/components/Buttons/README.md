# Buttons
The secondary button, the quality chip and the disclosure, the system's only controls besides tabs and segments.

- **Button:** `surface` fill, `rule-strong` border, `r-md`, 44px, weight 600.
- **Quality chip:** a pill in `rule-strong`, Label at 600; low quality is dashed with `ink-2` text.
- **Why this leads:** a native `details`; each rule has an 8px ring, filled `rain-3` when met; the leading rule is `ink` at 600.
- Focus everywhere: a 3px `rain-3` outline at 2px offset.
