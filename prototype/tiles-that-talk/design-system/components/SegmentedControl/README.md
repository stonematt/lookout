# SegmentedControl
A row of mutually exclusive buttons that switch a chart's scale or measure.

- 1px `rule-strong` border, `r-md` corners, `surface` buttons 40px high in `ink-2`, `rule` dividers.
- Pressed: `ink` fill, `ground` text, 650. Meets 4.5:1 in both themes.
- Consumer supplies: the options and which is pressed.
