# StoryBlock
The unit of every Lookout section: kicker, finding headline, one-line standfirst, chart, source note.

- **Headline** states the finding with its number (Headline for the lead, Title for others). Quiet 600; the chart outranks it.
- **Standfirst** is one line on how to read the chart, max 62ch.
- **Chart** is the highest-contrast element, with one `note` claret subject.
- **Kicker** (proposed): a sentence-case 0.8125rem label naming the subject; a `note` dot only when this section is the live finding.
- **Source note** (proposed): a closed SourceNote instead of the 3–5 line paragraph. See SourceNote.
- Consumer supplies: headline, standfirst and source text from the snapshot; the chart.
