# Tabs
Sticky section tabs on the ground colour with a hairline below.

- 46px minimum height, 0 14px padding, Body size in `ink-2`; selected is `ink` at 650 with a 3px inset `rain-3` underline.
- Square corners. The focus ring sits inside the bar so the sticky edge never clips it.
- Roving tabindex; arrows, Home and End move; the hash tracks the tab.
- Source: `web/src/tabs.ts`, `styles/base.css`.
