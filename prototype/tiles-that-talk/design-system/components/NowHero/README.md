# NowHero
The current temperature in Display type beside the station's condition sentence; the first thing on every phone screen.

- The temperature is the only Display text in the system. Tabular digits, superscript °F at 0.4em.
- The sentence is Body, written by Python from the live reading. The site never composes it.
- Consumer supplies: the live temperature and the condition sentence from the snapshot.
- Source: `web/src/overview/hero.ts`, `first-screen.css`.
