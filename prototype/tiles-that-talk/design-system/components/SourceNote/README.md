# SourceNote
Proposed. The source line folded into a native `details`: one line, closed, with the full method a tap away.

- **Summary:** "Source · archived <time>" in Source type, `ink-2`, on a `rule` hairline, 32px target, chevron at the right.
- **Flag:** when the archive lags more than 15 minutes, or a gap hides part of the chart, the summary carries a hatched chip with the short reason. That is the only time a caveat shows unopened.
- **Body:** the existing source paragraph, unchanged. Python still writes it; the site only folds it.
- The chart's in-place hatch and "n/a" labels stay. The note explains, it never replaces them.
- Snapshot change: a `source.summary` and an optional `source.flag` beside the existing text, so the site does not decide what matters (bump `SCHEMA_VERSION`).
